# 인게임 전체 레이아웃 수정 설계

## 목표

`우주 함장.png`의 세로형 구성을 기준으로 기존 인게임 HUD를 재배치한다. 기존 이미지, 색상, 게임 동작과 데이터 연결은 변경하지 않는다.

## 배치

- 기준 해상도는 현재 CanvasScaler의 `1080 x 1920`을 유지한다.
- 상단에는 레벨/경험치와 모드, 배속, 시간, 웨이브, 점수 정보를 압축 배치한다.
- 캐릭터 슬롯 1~5는 화면 오른쪽에 위에서 아래로 정렬한다.
- 슬롯 1~3은 전투, 4~5는 예비 영역으로 시각적으로 구분한다.
- 함선 스킬은 화면 하단 왼쪽에 가로로 정렬한다.
- 함선 마스터 스킬은 화면 하단 오른쪽에 배치한다.

## 구현 범위

- `Assets/_Game/Scenes/InGame.unity`의 기존 UI RectTransform과 관련 위치 값만 수정한다.
- 기존 UI 오브젝트, Sprite, 버튼 이벤트, `SkillSlotUI`, `ShipSkillButton`, `PlayerSwapManager`, `UImanager` 연결을 그대로 유지한다.
- 새 스크립트, 새 에셋, 새 UI 컴포넌트, 별도 레이아웃 시스템은 추가하지 않는다.

## 동작 보존

- 캐릭터 선택과 전투/예비 교대가 기존과 동일하게 동작해야 한다.
- 교대 쿨다운 표시와 스킬 버튼 입력이 기존과 동일하게 동작해야 한다.
- 배치 대상이 아닌 게임 월드 오브젝트와 런타임 로직은 변경하지 않는다.

## 검증

- 씬 diff에서 RectTransform과 승인된 위치 값 외 변경이 없는지 확인한다.
- Unity 컴파일 완료 후 Console 오류가 없는지 확인한다.
- PlayMode에서 슬롯 1~5 선택, 전투/예비 교대, 함선 스킬 입력을 확인한다.
- `1080 x 1920` Game View에서 상단 HUD, 오른쪽 슬롯, 하단 버튼이 겹치거나 화면 밖으로 나가지 않는지 확인한다.
